# Python Architecture, OOP & Algorithm Reference Library

An extensive library of 39+ production-grade Python scripts and interactive notebooks covering OOP paradigms, design patterns, regular expressions, file I/O, and mathematical algorithms.

Developed by **Aadarsh Sinha** ([@Monarch666](https://github.com/Monarch666)).

---

## 🐍 Topics & Code Modules

- **Object-Oriented Programming (OOP)**: Inheritance, polymorphism, abstract base classes, dunder methods, and encapsulation.
- **Regular Expressions**: Tokenizers, email/phone/date extractors, and substitution pipelines.
- **Functional Python**: Higher-order functions, map/filter/reduce, lambda expressions, and generator iterators.
- **Robust Exception Architecture**: Custom exception classes, context managers (`with` statements), and defensive error logging.
